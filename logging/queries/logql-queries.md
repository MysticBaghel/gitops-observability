
# LogQL Queries

This document contains commonly used LogQL queries for monitoring and troubleshooting the `gitops-demo` application through Grafana Loki.

## 1. All Application Logs

Display all logs collected from the application namespace.

```logql
{namespace="gitops-demo"}
```

## 2. FastAPI Container Logs

Filter logs generated by FastAPI containers.

```logql
{namespace="gitops-demo", container="fastapi"}
```

## 3. Logs From a Specific Pod

Filter logs from a particular FastAPI pod.

```logql
{namespace="gitops-demo", pod=~".*"}
```

## 4. Error Logs

Find log entries containing ERROR.

```logql
{namespace="gitops-demo"} |= "ERROR"
```

## 5. Warning Logs

Find log entries containing WARNING.

```logql
{namespace="gitops-demo"} |= "WARNING"
```

## 6. Successful HTTP Requests

Find HTTP 200 responses.

```logql
{namespace="gitops-demo"} |= "200 OK"
```

## 7. HTTP 5xx Errors

Find server-side HTTP errors.

```logql
{namespace="gitops-demo"} |~ " 5[0-9][0-9] "
```

## 8. Log Volume Per Minute

Count application log lines over the last minute.

```logql
sum(count_over_time({namespace="gitops-demo"}[1m]))
```

## 9. Logs From the FastAPI Container With Errors

```logql
{namespace="gitops-demo", container="fastapi"} |= "ERROR"
```

---

## Labels Available

| Label | Description |
|---|---|
| namespace | Kubernetes namespace |
| pod | Kubernetes pod name |
| container | Container name |
| instance | Pod/container identity |
| job | Alloy log collection job |
| service_name | Detected service name |

## Usage

1. Open Grafana.
2. Navigate to Explore.
3. Select the Loki datasource.
4. Switch the query editor to Code mode.
5. Enter a LogQL query.
6. Select Run query.

**Datasource:** Loki

**Application namespace:** `gitops-demo`
